# 🤖 Discord Bot Status & Ping Logger

A lightweight, asynchronous Discord bot built with `discord.py` that periodically monitors API latency, connected servers, and user metrics, logging everything with timestamps.

## 🚀 Features
- ⚡ **Real-time Latency Check:** Measures Discord API ping in milliseconds.
- 📊 **Server & User Metrics:** Tracks total guild count and members.
- 📝 **Automated File Logging:** Writes log entries directly to `bot_status.log`.
- 🔄 **Async Loop:** Uses `discord.ext.tasks` for efficient background execution.

## 🛠️ Tech Stack
- **Language:** Python 3.x
- **Library:** `discord.py`
